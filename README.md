# ✈️ Ray Aero – Aircraft Data/Specs Viewer

**Ray Aero** is a lightweight, fast, and intuitive Android app that lets you view data/specs about different aircraft types.
Whether you’re an aviation enthusiast or a flight tracker, AeroTrack gives you clean, detailed, and easy-to-read information.

---

## 🚀 Features

- **Detailed Aircraft Specs**
- **Aircraft Pics**
- **Offline Mode** – Most features can be used offline.

---


## 📥 Installation

You can download the latest APK directly from the **[Releases](../../releases)** section of this repository.

1. Go to **[Releases](../../releases)**.
2. Download the latest `.apk` file.
3. Enable *Install from Unknown Sources* on your device.
4. Install and open the app.

---

## 🔧 Usage

1. Launch the app.
2. Tap any aircraft for full specs.
